# AFTA Security Skill

مهارت مشترک برای توسعه و بررسی امنیت پروژه‌ها بر اساس نسخهٔ ۱٫۹ سند الزامات امنیتی برنامه‌های کاربردی تحت شبکه.

پشتیبانی از **Claude Code، GitHub Copilot، Cursor و Codex**، شامل **۷۹ الزام اصلی** و **۳۰۷ ردیف گزینه و توضیح**. نسخهٔ بسته: **1.1.0**.

## نصب

پس از دریافت مخزن، در پوشهٔ آن اجرا کنید.

Bash:

```bash
bash ./install.sh --agent all --scope user
```

Windows PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Agent all -Scope user
```

برای نصب پروژه‌ای، انتخاب ابزار، پیش‌نمایش و به‌روزرسانی همراه پشتیبان‌گیری، [راهنمای نصب](INSTALL.md) را ببینید.

## استفاده

```text
از مهارت afta-security برای بررسی این پروژه بر اساس چک‌لیست افتا نسخهٔ ۱٫۹ استفاده کن.
برای هر بند شاهد، وضعیت، کمبود و اقدام بعدی بنویس.
```

دستورها و منابع در [SKILL.md](afta-security/SKILL.md) هستند. ابزار اختیاری ساخت و اعتبارسنجی گزارش به Python 3.9 یا جدیدتر نیاز دارد؛ نصب و استفاده از متن مهارت به Python وابسته نیست.

## دامنه و منبع

متن عمومی الزامات از یک سند ارسالی استخراج شده و پاسخ‌ها و انتخاب‌های محصول قبلی حذف شده‌اند. سند Word اولیه و داده‌های پروژه‌های شرکت در این مخزن نیستند. اصالت و آخرین‌بودن سند مستقلاً تأیید نشده است. منشأ، اثر انگشت فایل و ابهام‌های متن در [یادداشت منبع](afta-security/references/source-notes.md) ثبت شده‌اند. این ابزار جای تأییدیهٔ رسمی یا بررسی مسئول امنیت را نمی‌گیرد.

آزمون‌های نصب Bash و PowerShell 7 روی Linux اجرا شده‌اند؛ اجرای مستقیم Windows و خود عامل در چهار محصول آزمایش نشده است.
